# Code Of Conduct

Nigerian Lit is a community archive for readers, students, writers, and contributors.

Be respectful when discussing books, authors, schools, publishers, booksellers, and other contributors. Assume good faith, but keep corrections factual and specific.

Harassment, insults, threats, spam, or discriminatory language are not welcome in issues, pull requests, discussions, or project spaces.

If you see a problem, open an issue or contact the project maintainer through the repository.
