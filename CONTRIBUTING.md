# Contributing

Thank you for helping improve Nigerian Lit.

This project is a discovery archive. Contributions should help readers find accurate information about Nigerian and West African literature without hosting or copying copyrighted works.

## Ways To Help

- Recommend missing books, plays, poems, and authors.
- Report broken, blocked, or incorrect links.
- Add legitimate Nigerian or West African bookstore links.
- Correct metadata such as title, author, genre, publication year, or school category.
- Improve the interface, accessibility, search, filtering, or sharing experience.

## What Not To Add

Do not add:

- Full copyrighted book text.
- Book PDFs or scans.
- Links to pirated downloads.
- Long excerpts from copyrighted works.
- Cover images copied from sites that do not allow reuse.
- Claims that the archive owns or represents a book, author, publisher, or bookseller.

## Book And Link Guidelines

When adding a book or source link:

- Prefer publisher pages, author pages, Nigerian bookstores, library records, and verified catalog pages.
- Use direct book pages when a store has the exact book.
- Use search links only when a direct listing is not available.
- Do not add a store link just because the store exists; add it only when it is useful for that book.
- If a source may not work for Nigerian readers, mark it carefully or prefer a Nigerian source.

## Pull Requests

Before opening a pull request:

```sh
npm run lint
npm run build
```

If you change recommendation or report form fields, also update the matching Apps Script or API handler.

## Rights Requests

If you are a rights holder and want a link, cover image, source, or listing reviewed or removed, please use the report form on the live site.
